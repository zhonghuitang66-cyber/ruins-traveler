# 独立部署与验收

部署目录为 `/www/wwwroot/vibehack`。原网站 `/www/wwwroot/36.137.144.180` 及899端口的配置、文件和Nginx主进程保持原样；部署前后原页面SHA256均为 `b7005a1d038cd13cf58aaaa0fe0601912388ca46560d1acd1968f6080896cfb6`。

| 服务 | 地址与用途 |
|---|---|
| 网页及APK下载 | `http://114.66.36.160:9088/`、`/downloads/` |
| APK联机API | `https://114.66.36.160:9443/api/` |
| WebSocket | `wss://114.66.36.160:9443/ws` |
| 后端内部监听 | `127.0.0.1:8787`，不直接公开 |
| 数据库 | `vibehack/data/accounts.sqlite`，在公开静态根目录之外 |

静态根目录是 `vibehack/current`，指向独立版本目录；源码后端、数据库和TLS私钥均不在静态根内。专用Nginx使用自己的PID与配置，不调用原站的重启或重载。Python3.6标准库服务以独立无登录账号运行，设置内存、文件句柄和CPU限额；不安装系统库，不升级原运行环境。

`vibehack-web.service`、`vibehack-online.service`管理新服务。`vibehack-cert-renew.timer`每日两次检查独立游戏证书；剩余不足30天时续签90天叶证书，并只平滑重载游戏Nginx。专用CA根有效至2029-10-30，届时需提前更换根并更新APK。公网无法使用80/443的IP证书验证入口，故浏览器版本保持离线；玩家不需要手动信任证书，APK已按固定IP声明额外CA。没有忽略证书错误或关闭混合内容保护。

账号仅需用户名。本机保存随机设备码与随机登录令牌；同设备码只能注册一次，服务端仅存哈希。清除应用数据会失去本机凭据，因此恢复机制不等同于密码账号。用户名使用白名单，JSON输出转义，排行榜用textContent，SQLite使用参数化SQL。财富按需求完全信任客户端，不提供防作弊保证。

完整地图只初始化一次；双方原技能与背包操作由权威玩家统一计算。权威离开后对方用当前快照继续人机，不迁移尚未执行的技能定时事件；关键状态恢复后取消旧蓄力。服务重启会关闭当前房间，账号与财富仍由SQLite保留。

公网实际验证：双人匹配1.412秒，完整初始化1.750秒，服务端单人回退30.002秒，六模型12,965,056字节全部校验一致。此结果来自两个本地Game客户端通过真实公网API/WSS互联，不能冒称双手机视觉实机验收。
