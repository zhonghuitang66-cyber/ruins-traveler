# 遗迹旅人 / Ruins Traveler

Three.js 搜打撤游戏，支持离线试玩与 Android 双人联机。三位旅人进入金色遗迹，在8分钟内搜寻、战斗和撤离；营地选择的装备与携带物会真正承担本局死亡风险。

## 原创玩法

- 四角出生与三个遗迹猎手：人机先搜寻、打怪与穿装备，区域搜索完或3分钟后按分钟顺序追踪玩家。
- Boss使用精确分段3秒蓄力与血盾同槽；玩家四段攻击、冰霜延迟连射、隐身加速与反应式装备组合形成不同撤离策略。
- 合成球消耗两件物品、一次性药铺、菜田和池塘，让低风险采集与高风险收藏构成路线选择。
- 以单格价值筛选整批拾取；营地选择装备和最多5件携带物，退出/死亡损失本局携带物，撤离后可出售本局净新增低品质物品。

本项目从本轮自然语言需求开始构建；2026-10-31按用户要求更名为《遗迹旅人》。改名不是原创依据，具体机制和实现见源码与开发日志。没有导入一套现成游戏再替换标题。

## 本地运行

需要Node.js，第三方Three.js模块已随仓库保存，不需要下载npm依赖。

```sh
npm start
```

打开 http://localhost:4173 。WASD移动，J攻击，1/2/3技能，空格闪避，E交互，F按住撤离；触屏使用轮盘与按钮。

关键测试使用 `node --test --test-isolation=none tests/*.test.mjs`。当前428项自动测试通过，含双人战斗、共享物品、背压、初始化、断线接管和插值。后端另有Node与Python协议测试。自动测试不等同于双手机实机战斗、触控或主观听感验收。

Android构建脚本为 `android/build.py`，需要本机JDK、Android SDK build-tools 35.0.1及ANDROID_JAR指向的平台jar。签名密钥只保存在本机工作目录，不提交；同签覆盖安装依赖原密钥。APK不包含生成API或服务凭据。

## 联机与服务器负担

双人同图可互相战斗、争夺共享物资并独立撤离。由一台玩家设备计算完整战斗，另一台预测本地移动；服务器仅负责匹配、消息转发、账号和财富榜，停止重复轮询。访客输入仅在变化时发送，持续操作每0.5秒续传；权威状态8Hz差量、每秒完整关键帧，远端125ms插值，可靠交互带幂等编号和回执。断线保留当前遗迹，由人机继续行动。

财富由本机营地物品、装备和收藏计算，服务端按需求信任提交值，榜单缓存10分钟、显示前100名；这不是反作弊经济系统。用户名白名单、JSON安全输出、界面textContent和SQLite参数化查询共同防止脚本及SQL注入。

独立后端兼容服务器现有Python3.6，只用标准库；不升级现有服务器环境。部署目录、端口、证书与验证范围见[部署说明](docs/deployment.md)，优化依据见[网络研究记录](docs/network-research.md)。
